# Z-Score to Value

The inverse of a z-score problem. Each question gives a mean, a standard deviation and a z-score in a short real-world setting (test scores, heights, commute times and more), and students type the value that has that z-score. Three levels: whole z, half z, and one-decimal z. Feedback names common slips: adding when z is negative, giving only z times the standard deviation, or adding z straight to the mean. Two hints fill in a worked solution (formula, then substitution), and Show answer finishes it. A number line fills in its values once the question is done. First-try score and streak are kept on the page only.

Open `index.html` in a browser, no build step needed.
